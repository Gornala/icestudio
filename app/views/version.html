What's new in this build

Left Panel — Design Explorer

A collapsible left panel gives a live overview of the whole design:

  • Modules — all sub-modules and code blocks
  • Consts — constant parameters with inline value editing
  • Memory — memory blocks with entry count
  • Info — information/comment blocks (refreshes as you type)
  • Ports — virtual I/O ports
  • Wires — label wires grouped by name
  • HW Pins — FPGA-assigned pins with pin dropdown

Click any item to highlight it on the canvas; double-click to open its editor.

UI Themes

A custom theme option has been added alongside the existing dark and light themes. Set your own background, sidebar, border, text, and accent colours in the Preferences panel.

Custom Board Manager

Boards can now be added, edited, and removed directly inside the app. Define your own FPGA target without editing configuration files by hand.

Code Block — Full Editor & Verification

The code block now opens a full-featured editor with:

  • Syntax-highlighted Verilog editor with port table auto-population
  • Formal verification — run a bounded model-check and view a waveform of any counter-example
  • Testbench runner — simulate with an .ice testbench and inspect results in the built-in waveform viewer
  • Waveform viewer — canvas-based viewer with draggable A/B markers, edge counting, and GTKWave integration

Collection Manager — Reworked

The collection panel has been completely redesigned as a permanent sidebar with:

  • Tree and table views with live search filtering
  • V / F / T / B status badges per block (Verified, Formal, Testbench, Build)
  • Add collections from zip, folder, or single .ice file
  • Remove individual blocks or entire collections inline
  • Adapts to the active UI theme automatically
